# 1.1.0

Five more Minecraft versions, and a fix for the Key Binds screen.

**Now available for 1.21.11, 1.21.8, 1.21.1, 1.20.1 and 1.19.2**, alongside
26.2. Presets are shared between all of them: the folder lives outside any game
directory, so a preset saved on 1.20.1 is already there when you launch 26.2.
Binds the older version has never heard of stay in the file rather than being
dropped, so nothing is lost on the way through.

**Fixed: the Key Binds screen no longer shows stale keys after applying a
preset.** Applying from the vanilla Key Binds screen left it displaying the old
keys until you closed and reopened it. The binds were always applied correctly —
only the screen was behind — but there was no way to tell that from looking at
it. Affected 1.20.1 and later; 1.19.2 never had the problem.

# 1.0.0

First release, for Minecraft 26.2.

Save your keybinds as presets and swap between them in two clicks, or one
keypress. Presets live outside the instance folder, so the same set follows you
into every modpack, launcher, Minecraft account and version on the PC.
